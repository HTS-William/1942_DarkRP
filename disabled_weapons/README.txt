Weapons from the Military Conflict: Vietnam pack that aren't used on this
server (Vietnam-era guns). Kept here, OUTSIDE lua/, so Garry's Mod never
loads them. (A folder inside lua/weapons/ is read as a weapon, which is what
caused "AddCSLuaFile: Couldn't find 'weapons/disabled/shared.lua'".)

To use one: move its file into lua/weapons/ and restart.
